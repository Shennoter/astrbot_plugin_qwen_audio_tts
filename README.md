## 单次指定读音与自然语言调用

聊天模型需支持工具调用，并在 AstrBot 的工具管理中启用这三个插件工具：`qwen_speak`、`qwen_voice_control`、`qwen_voice_dictionary`。如果当前人设或会话限制工具，还需将它们放进允许范围。插件设置中的“自然语言调用”也需启用。

可以直接对机器人说：

```text
用日语读一下“鳳凰院凶真”，这次把它读成“ほうおういん きょうま”。
用英语说“Hello, nice to meet you.”。
用温柔的语气读这句话：今天也辛苦了。（需选择 instruction 或 both 模式）
把随机语音概率设为 30%，最大字数设为 300。（管理员）
以后都把“鳳凰院凶真”读成“ほうおういん きょうま”，加入词典。（管理员）
看看语音替换词典。
删除词典里“鳳凰院凶真”的读音。（管理员）
把单次发音模式改成 both。（管理员）
```

自然语言由聊天模型转换为工具参数，不是靠关键词直接触发；模型需要实际调用工具才能发送语音或修改设置。工具会执行权限、会话范围、字数和冷却检查，失败时返回真实错误。自然语言修改的设置/词典是**全局配置**，仅管理员可以写入，普通用户可以按命令权限朗读和查看状态。不要把“这次这样读”理解成“永久加入词典”。

在“单次发音控制与持久替换词典”中选择发送方式：

| 模式 | 当前请求如何处理 |
| --- | --- |
| `hot_fix`（默认） | 采用单次结构化读音映射；如果同时有单次 instruction，则不发送这条单次 instruction。只有 instruction 而没有映射时明确提示切换模式 |
| `instruction` | 使用本次自然语言指令；如果给了单次映射，则把映射转为“将某词读作某读音”的指令，并暂时移除同词的基础/词典规则 |
| `both` | 同时采用本次 hot_fix 和 instruction |

该选择只控制**单次覆盖参数**。音频页的全局 instruction/hot_fix 及单独启用的持久词典仍作为基础配置使用。指令模式不能保证准确发音；对于日语人名，推荐 `hot_fix.replace` 替换为假名，不假定 `pronunciation` 支持日语罗马音。相关结构依据[阿里云 HTTP API](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)。

单次参数只存在于这一次合成调用中，不写入配置、不留在会话里供下一次使用，也不会串到其他并发会话。显示原文和语音附带的文本仍为用户的原句。

不使用聊天模型工具时，也可手动输入单次参数：

```text
/说话参数 ja {"text":"鳳凰院凶真","hot_fix":{"replace":[{"鳳凰院凶真":"ほうおういん きょうま"}]}}
/说话参数 zh {"text":"今天也辛苦了。","instruction":"请用温柔、轻松的语气表达。"}
```

第二个例子需在设置中选择 `instruction` 或 `both`。也可以在同一个 JSON 中同时给出 `hot_fix` 与 `instruction`，由当前模式选取。

## 持久替换词典

在设置中的“持久替换词典（JSON）”直接编辑并保存，例如：

```json
{
  "鳳凰院凶真": "ほうおういん きょうま",
  "OpenAI": "Open A I"
}
```

词典保存于 AstrBot 管理的插件配置中，重载或重启后仍保留。支持单独启用/停用，以及 `all`、`zh`、`en`、`ja` 语言范围。非 all 的词典只对明确指定对应语言的请求生效，不猜测 auto 的语种。

每次合成都会把词典合并为 `hot_fix.replace`，包括自动语音、手动命令、自然语言工具以及内置兼容调用。**同词优先级：单次读音 > 持久词典 > 音频页基础 hot_fix**；跨 replace/pronunciation 冲突时也只保留优先项。未冲突的规则继续保留。原文不在本地被替换后发送给用户；接口接收原文和替换参数。词典是字面映射，不支持正则表达式；客户端使用最长词优先、非递归替换估算展开长度，超出字数上限时拒绝合成。

在官方合并 [PR #10495](https://github.com/AstrBotDevs/AstrBot/pull/10495) 之前，使用插件修复内置 DashScope 对 `qwen-audio-*` 的接口选择和业务空间域名问题，并提供随机语音回复、中英日朗读及参数设置。

## 安装与首次设置

1. 在 AstrBot 插件管理中使用仓库地址 `https://github.com/Shennoter/astrbot_plugin_qwen_audio_tts` 安装。也可下载仓库 ZIP，通过本地 ZIP 安装，或解压为 `data/plugins/astrbot_plugin_qwen_audio_tts/`，确保该目录下直接包含 `main.py` 与 `metadata.yaml`，然后重启 AstrBot。
2. 模型管理中保留原有的内置 `dashscope_tts` 提供商，填写 API Key、模型 ID 和对应音色 ID，并启用该提供商。不要将提供商删除。
3. 打开插件设置，在“连接与兼容修复”填写自己的业务空间 ID/完整域名。提供商 ID 指模型管理页面最上方的 ID，不是音色 ID；可填写已启用提供商的 ID，留空则跟随当前会话选择的 TTS。公开版本不会预填任何人的业务空间或密钥。
4. 保存后重载插件。回模型管理点击测试；插件启用期间内置 `qwen-audio-*` 请求通过业务空间 HTTP 接口合成。
5. 使用插件的随机语音时，请关闭 AstrBot 的“自动 TTS”全局开关，并关闭聊天流式输出。提供商本身仍保持启用。原生自动 TTS 开启时，插件随机转换会主动跳过以免重复计费；兼容修复和手动朗读仍工作。

包内不包含 API Key、训练录音或你的 `.env`。每次请求从被选中提供商读取其自己的密钥，不修改 DashScope 全局配置。插件没有新依赖，使用 Python 标准库。

## 随机语音

默认转换 20% 的符合条件的完整 AI 回复，最多 200 字，同一会话间隔至少 10 秒。概率范围 0～100，可以在设置页面调整。

- 达到最大字数、冷却中、抽取未命中、包含图片/卡片/语音等非文字组件时，发送原消息。
- 默认跳过代码块；可清理用于朗读的 Markdown、网址和图片链接。原始文字不会被清理或截断。
- 最大字数是清理后 Python Unicode 字符数，包括标点、空格和英文字母，不是英文单词数。多段文字合并后检查上限，每个结果抽取一次。超过上限不会偷偷截断。
- 可以选择只发语音，或语音和原文同时发送。合成/下载失败时保留原始文字。
- 可以设置仅私聊、仅群聊、平台白名单、会话白名单/黑名单。黑名单优先。`/语音状态` 可查看会话标识。
- 仅拦截 AstrBot 发送前钩子中的完整结果；不拦截其他插件直接 `event.send()` 的主动消息，也不拦截已经开始发送的流式片段。

## 指定语言朗读（不翻译）

```text
/说话 zh 你好，很高兴认识你。
/说话 en Hello, nice to meet you.
/说话 ja こんにちは。お会いできてうれしいです。
```

命令别名：`/朗读`、`/qvoice`。语言也可填写 `中文`、`汉语`、`英语`、`日语` 等名称。使用同一个复刻音色跨语言朗读，实际效果取决于模型和参考录音。给中文文字加 `en` 不会自动翻译为英文。指定句子同样受最大字数、会话范围和并发数限制，但不受随机概率限制。默认任何用户可用，可设为仅管理员使用，默认同用户同会话冷却 3 秒。

管理员可在聊天中修改全局设置，也支持上文的自然语言工具：

```text
/语音设置 概率 30
/语音设置 字数 300
/语音设置 开关 开
/语音设置 开关 关
/语音设置 发音模式 both
/语音设置 词典开关 开
```

具体命令前缀按 AstrBot 的唤醒/命令前缀设置使用；本说明以 `/` 为例。

## 模型和音色

在内置提供商设置中选择模型和对应复刻音色；随机语音和朗读命令使用插件配置中的提供商。下面是格式示例，请替换为自己账户中创建的实际音色 ID：

| 模型 | 音色格式示例 |
| --- | --- |
| `qwen-audio-3.1-tts-plus` | `qwen-audio-3.1-tts-plus-myvoice-实际唯一标识` |
| `qwen-audio-3.1-tts-flash` | `qwen-audio-3.1-tts-flash-myvoice-实际唯一标识` |

复刻音色属于创建它们的账户和业务空间，不能直接使用示例字符串。切换模型必须切换匹配音色。CosyVoice、Qwen3-TTS 和其他提供商继续走原逻辑，本插件的参数和随机朗读仅面向 Qwen-Audio-TTS。

## 参数面板

按[阿里云非实时 HTTP API](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)传入 `input`：

| 设置 | 默认 | 范围或说明 |
| --- | --- | --- |
| 格式 `format` | wav | wav / mp3 / opus；PCM 缺少文件头，不作为直接发送选项 |
| 采样率 `sample_rate` | 24000 | 8000 / 12000 / 16000 / 22050 / 24000 / 44100 / 48000；Opus 不支持 22050、44100 |
| 音量 `volume` | 50 | 0～100 |
| 语速 `rate` | 1.0 | 0.5～2.0 |
| 音调 `pitch` | 1.0 | 0.5～2.0 |
| Opus 码率 `bit_rate` | 32 | 6～510，仅 Opus 时发送 |
| 种子 `seed` | -1 | -1 不指定；0～65535 固定种子 |
| 目标语言 `language_hints` | auto | auto 不传；可选 zh / en / ja；命令参数优先 |
| 情绪指令 `instruction` | 空 | 可描述情感、方言和说话方式，具体模型支持情况以服务为准 |
| `enable_ssml` | false | 只用于手动朗读与内置测试，普通自动聊天始终关闭；开启时需正确 SSML |
| `hot_fix` | 空 | pronunciation 和 replace 的 JSON 配置，设置面板内有示例 |
| AIGC 标识及传播者字段 | 关闭/空 | 开启后发送对应参数；修正 WAV 文件头时保留其他数据块 |

本插件采用非流式 HTTP 合成后发送完整文件，没有暴露仅流式模式可用的字级时间戳参数。不要同时开启原生自动 TTS 与插件随机转换。模型不支持某个参数时接口会返回错误；可以先清空 instruction / hot_fix 等可选设置再检查。

超时默认单次操作 60 秒；不自动重试已发送的合成请求，避免重复计费。最大并发默认 2，可设置 1～8。插件目录中的语音默认保留 24 小时；下次合成触发按小时清理，不是精确定时任务。支持可选 AstrBot 文件服务，适合适配器和 AstrBot 分离部署，需要先配置可访问的 `callback_api_base`。

## 官方合并后的使用

可在插件设置关闭“修复内置调用”并重载，继续保留随机语音和朗读功能。停用/卸载插件会恢复它自己安装的内置类方法；不会覆盖其他插件后来安装的补丁。请勿安装本插件的多个副本。

兼容性依据为本次检查的 AstrBot 上游 `master` 提交 `1b10813c70949071fa11153cc4ec8c51421d13d0`，不保证后续改变内部接口的版本。此插件会在进程内临时替换内置类的 `get_audio` 方法，未修改 AstrBot 源文件。
