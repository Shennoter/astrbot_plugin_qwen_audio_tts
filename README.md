# Qwen Audio 语音助手

当前版本：**0.3.0**。独立配置 API Key、业务空间、模型和音色，不需要创建或启用 AstrBot 内置 TTS 提供商。更新后先填写本插件的“语音服务配置”并保存，然后重载插件。

## 单次指定读音与自然语言调用

聊天模型需支持工具调用，并在 AstrBot 的工具管理中启用这四个插件工具：`qwen_speak`、`qwen_voice_preview`、`qwen_voice_control`、`qwen_voice_dictionary`。如果当前人设或会话限制工具，还需将它们放进允许范围。插件设置中的“自然语言调用”也需启用。

可以直接对机器人说：

```text
用日语读一下“鳳凰院凶真”，这次把它读成“ほうおういん きょうま”。
用英语说“Hello, nice to meet you.”。
试听一下当前音色。（默认仅管理员）
用温柔的语气读这句话：今天也辛苦了。（需选择 instruction 或 both 模式）
把随机语音概率设为 30%，最大字数设为 300。（管理员）
以后都把“鳳凰院凶真”读成“ほうおういん きょうま”，加入词典。（管理员）
看看语音替换词典。
删除词典里“鳳凰院凶真”的读音。（管理员）
把单次发音模式改成 both。（管理员）
```

自然语言由聊天模型转换为工具参数，不是靠关键词直接触发；模型需要实际调用工具才能发送语音或修改设置。工具会执行权限、会话范围、字数和冷却检查，失败时返回真实错误。自然语言修改的设置/词典是**全局配置**，仅管理员可以写入，普通用户可以按命令权限朗读和查看状态。不要把“这次这样读”理解成“永久加入词典”。

在“单次发音控制与持久替换词典”中选择发送方式：

| 模式 | 当前请求如何处理 |
| --- | --- |
| `hot_fix`（默认） | 采用单次结构化读音映射；如果同时有单次 instruction，则不发送这条单次 instruction。只有 instruction 而没有映射时明确提示切换模式 |
| `instruction` | 使用本次自然语言指令；如果给了单次映射，则把映射转为“将某词读作某读音”的指令，并暂时移除同词的基础/词典规则 |
| `both` | 同时采用本次 hot_fix 和 instruction |

该选择只控制**单次覆盖参数**。音频页的全局 instruction/hot_fix 及单独启用的持久词典仍作为基础配置使用。指令模式不能保证准确发音；对于日语人名，推荐 `hot_fix.replace` 替换为假名，不假定 `pronunciation` 支持日语罗马音。相关结构依据[阿里云 HTTP API](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)。

单次参数只存在于这一次合成调用中，不写入配置、不留在会话里供下一次使用，也不会串到其他并发会话。显示原文和语音附带的文本仍为用户的原句。

不使用聊天模型工具时，也可手动输入单次参数：

```text
/说话参数 ja {"text":"鳳凰院凶真","hot_fix":{"replace":[{"鳳凰院凶真":"ほうおういん きょうま"}]}}
/说话参数 zh {"text":"今天也辛苦了。","instruction":"请用温柔、轻松的语气表达。"}
```

第二个例子需在设置中选择 `instruction` 或 `both`。也可以在同一个 JSON 中同时给出 `hot_fix` 与 `instruction`，由当前模式选取。

## 持久替换词典

在设置中的“持久替换词典（JSON）”直接编辑并保存，例如：

```json
{
  "鳳凰院凶真": "ほうおういん きょうま",
  "OpenAI": "Open A I"
}
```

词典保存于 AstrBot 管理的插件配置中，重载或重启后仍保留。支持单独启用/停用，以及 `all`、`zh`、`en`、`ja` 语言范围。非 all 的词典只对明确指定对应语言的请求生效，不猜测 auto 的语种。

每次合成都会把词典合并为 `hot_fix.replace`，包括自动语音、手动命令、自然语言工具和页面试听。**同词优先级：单次读音 > 持久词典 > 音频页基础 hot_fix**；跨 replace/pronunciation 冲突时也只保留优先项。未冲突的规则继续保留。原文不在本地被替换后发送给用户；接口接收原文和替换参数。词典是字面映射，不支持正则表达式；客户端使用最长词优先、非递归替换估算展开长度，超出字数上限时拒绝合成。

## 安装与首次设置

1. 在 AstrBot 插件管理中使用本仓库地址安装，或使用发布的安装 ZIP 更新。手动解压时，确保 `data/plugins/astrbot_plugin_qwen_audio_tts/` 下直接包含 `main.py` 与 `metadata.yaml`。
2. 打开插件设置中的“语音服务配置”，填写自己的 **API Key、业务空间、语音模型和匹配的音色 ID**。业务空间可填 `ws-xxx`（默认北京）或完整业务空间域名；其他地域需填完整域名。
3. 保存设置并重载插件，从插件详情打开“音色试听”可视化页面。输入文字、选择语言，点击“生成试听音频”，生成后在页面播放器中试听或下载。
4. 使用随机语音时，关闭 AstrBot 的原生“自动 TTS”和聊天流式输出，避免冲突。插件指定朗读和页面试听不依赖随机开关或概率。

从 0.2.x 升级时，原先保存在内置提供商里的 API Key、模型和音色不会自动搬入插件，需填写到本插件的“语音服务配置”。旧的提供商选择和兼容补丁配置已移除；重载后不再修改内置 TTS 类。

公开源码和安装包不包含私人 API Key、业务空间、训练录音或 `.env`。密钥只存放在用户自己的插件配置中，页面输入框默认遮罩；试听接口不把密钥返回浏览器。使用 Python 标准库合成，无需额外安装语音 SDK。

## 页面内试听

AstrBot 普通 `_conf_schema.json` 表单目前不支持任意按钮或音频播放器。本插件使用官方的 `views/preview/` 可视化视图，在同一管理面板内提供“音色试听”页面；入口位于插件详情页的可视化视图区域。不是在普通表单字段中嵌入播放器。

- 先保存插件配置，再打开试听页面；已打开时点击“刷新配置”，载入当前模型、音色及音频参数。修改参数后请再次保存和刷新。
- 页面可临时输入试听文字，选择汉语、英语、日语或跟随默认语言。只朗读原文，不自动翻译，不把临时文字/语言写回配置。
- 使用当前保存的音量、语速、音调、格式、全局 instruction/hot_fix 和持久词典，也受最大字数和全插件并发限制。
- 生成后显示浏览器原生播放器和下载链接，不自动播放；浏览器不支持某格式时可下载，或改用 WAV / MP3。
- 每次生成都调用阿里云服务，按其规则计费。不自动重试；页面禁止重复提交，后端限制一个正在进行的页面试听并设置冷却。
- 页面经 AstrBot 官方 bridge 调用后端，要求 Dashboard 登录和插件权限。无需聊天适配器，不受聊天会话白名单限制；`admin_only` 仅控制聊天中的自然语言试听。
- 已删除 `/语音试听` 和 `/试听`，不会注册替代试听指令。自然语言“试听当前音色”仍由 `qwen_voice_preview` 工具按聊天权限处理。

需要支持官方插件可视化视图、`AstrBotPluginView` bridge 和 `astrbot.api.web` 的 AstrBot 版本。本次按上游 `master`（版本号 4.29.1，提交 `1b10813c70949071fa11153cc4ec8c51421d13d0`）源码开发。旧版缺少页面扩展能力时，普通语音功能可继续使用，但页面试听需升级到包含这些能力的版本。详见[官方插件视图文档](https://github.com/AstrBotDevs/AstrBot/blob/master/docs/zh/dev/star/guides/plugin-pages.md)。

## 随机语音

默认转换 20% 的符合条件的完整 AI 回复，最多 200 字，同一会话间隔至少 10 秒。概率范围 0～100，可以在设置页面调整。

- 达到最大字数、冷却中、抽取未命中、包含图片/卡片/语音等非文字组件时，发送原消息。
- 默认跳过代码块；可清理用于朗读的 Markdown、网址和图片链接。原始文字不会被清理或截断。
- 最大字数是清理后 Python Unicode 字符数，包括标点、空格和英文字母，不是英文单词数。多段文字合并后检查上限，每个结果抽取一次。超过上限不会偷偷截断。
- 可以选择只发语音，或语音和原文同时发送。合成/下载失败时保留原始文字。
- 可以设置仅私聊、仅群聊、平台白名单、会话白名单/黑名单。黑名单优先。在目标会话发送 AstrBot 内置 `/sid`，将返回的 **UMO 完整值**复制到会话列表，不带「」；不要填写 UID 或单独的 Session ID。插件不再注册会话标识命令。
- 仅拦截 AstrBot 发送前钩子中的完整结果；不拦截其他插件直接 `event.send()` 的主动消息，也不拦截已经开始发送的流式片段。

## 指定语言朗读（不翻译）

```text
/说话 zh 你好，很高兴认识你。
/说话 en Hello, nice to meet you.
/说话 ja こんにちは。お会いできてうれしいです。
```

命令别名：`/朗读`、`/qvoice`。语言也可填写 `中文`、`汉语`、`英语`、`日语` 等名称。使用同一个复刻音色跨语言朗读，实际效果取决于模型和参考录音。给中文文字加 `en` 不会自动翻译为英文。指定句子同样受最大字数、会话范围和并发数限制，但不受随机概率限制。默认任何用户可用，可设为仅管理员使用，默认同用户同会话冷却 3 秒。

管理员可在聊天中修改全局设置，也支持上文的自然语言工具：

```text
/语音设置 概率 30
/语音设置 字数 300
/语音设置 开关 开
/语音设置 开关 关
/语音设置 发音模式 both
/语音设置 词典开关 开
```

具体命令前缀按 AstrBot 的唤醒/命令前缀设置使用；本说明以 `/` 为例。

## 模型和音色

在插件“语音服务配置”中选择模型和对应复刻音色；随机语音、朗读和试听均使用这里的配置。下面是格式示例，请替换为自己账户中创建的实际音色 ID：

| 模型 | 音色格式示例 |
| --- | --- |
| `qwen-audio-3.1-tts-plus` | `qwen-audio-3.1-tts-plus-myvoice-实际唯一标识` |
| `qwen-audio-3.1-tts-flash` | `qwen-audio-3.1-tts-flash-myvoice-实际唯一标识` |

复刻音色属于创建它们的账户和业务空间，不能直接使用示例字符串。切换模型必须切换匹配音色。本插件面向 Qwen-Audio-TTS，不处理 CosyVoice、Qwen3-TTS 或其他提供商。

## 参数面板

按[阿里云非实时 HTTP API](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)传入 `input`：

| 设置 | 默认 | 范围或说明 |
| --- | --- | --- |
| 格式 `format` | wav | wav / mp3 / opus；PCM 缺少文件头，不作为直接发送选项 |
| 采样率 `sample_rate` | 24000 | 8000 / 12000 / 16000 / 22050 / 24000 / 44100 / 48000；Opus 不支持 22050、44100 |
| 音量 `volume` | 50 | 0～100 |
| 语速 `rate` | 1.0 | 0.5～2.0 |
| 音调 `pitch` | 1.0 | 0.5～2.0 |
| Opus 码率 `bit_rate` | 32 | 6～510，仅 Opus 时发送 |
| 种子 `seed` | -1 | -1 不指定；0～65535 固定种子 |
| 目标语言 `language_hints` | auto | auto 不传；可选 zh / en / ja；命令参数优先 |
| 情绪指令 `instruction` | 空 | 可描述情感、方言和说话方式，具体模型支持情况以服务为准 |
| `enable_ssml` | false | 只用于指定句子和试听，普通自动聊天始终关闭；开启时需正确 SSML |
| `hot_fix` | 空 | pronunciation 和 replace 的 JSON 配置，设置面板内有示例 |
| AIGC 标识及传播者字段 | 关闭/空 | 开启后发送对应参数；修正 WAV 文件头时保留其他数据块 |

本插件采用非流式 HTTP 合成后发送完整文件，没有暴露仅流式模式可用的字级时间戳参数。不要同时开启原生自动 TTS 与插件随机转换。模型不支持某个参数时接口会返回错误；可以先清空 instruction / hot_fix 等可选设置再检查。

超时默认单次操作 60 秒；不自动重试已发送的合成请求，避免重复计费。最大并发默认 2，可设置 1～8。插件目录中的语音默认保留 24 小时；下次合成触发按小时清理，不是精确定时任务。支持可选 AstrBot 文件服务，适合适配器和 AstrBot 分离部署，需要先配置可访问的 `callback_api_base`。

## 验证情况

- 52 项离线测试覆盖独立配置、概率回复、会话范围、内置自动 TTS 冲突处理、发音模式、持久词典、自然语言工具，以及页面接口权限、参数校验、冷却、密钥隔离和错误处理。
- HTTP 客户端已使用 `qwen-audio-3.1-tts-plus` 复刻音色完成中文、英语、日语真实合成，以及单次 hot_fix 假名替换和 instruction 请求，均返回有效 WAV。测试确认接口和文件有效，不代表对口音、相似度或精确读音的主观评估。
- 0.3.0 的独立页面试听后端另完成一次真实请求，返回有效的 24 kHz、3.04 秒 WAV。浏览器前端使用模拟 bridge 验证了生成、失败恢复、Unicode 字数拦截和播放器解码。工作区没有运行中的完整 AstrBot 实例；实际安装后的插件详情入口、Dashboard bridge 和聊天平台投递仍需在目标实例验证。

在仓库根目录运行 `python run_tests.py`，无需安装 AstrBot 或提供 API Key。测试使用与所检查源码接口对应的轻量桩，不调用真实语音服务。仓库包含源码与离线测试；单独的安装 ZIP 仅包含运行文件、页面、许可证与说明，不包含密钥、音频或 Python 缓存。
