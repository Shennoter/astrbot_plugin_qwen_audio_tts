# 进阶使用与部署说明

[返回 README](../README.md) · [更新日志](../CHANGELOG.md)

## 单次指定读音与自然语言调用

聊天模型需支持工具调用，并在 AstrBot 的工具管理中启用这三个插件工具：`qwen_speak`、`qwen_voice_control`、`qwen_voice_dictionary`。如果当前人设或会话限制工具，还需将它们放进允许范围。插件设置中的“自然语言调用”也需启用。

可以直接对机器人说：

```text
用日语读一下“鳳凰院凶真”，这次把它读成“ほうおういん きょうま”。
用英语说“Hello, nice to meet you.”。
用温柔的语气读这句话：今天也辛苦了。
读“你好，出发吧！”，先低沉地读“你好，”，停半秒，再提高音调、激昂地读“出发吧！”。
用日语读“鳳凰院凶真”，名字读作“ほうおういん きょうま”，语气沉稳，句尾下降。
把随机语音概率设为 30%，最大字数设为 300。（管理员）
以后都把“鳳凰院凶真”读成“ほうおういん きょうま”，加入词典。（管理员）
看看语音替换词典。
删除词典里“鳳凰院凶真”的读音。（管理员）
把单次发音模式改成 both。（管理员）
```

自然语言由聊天模型转换为工具参数，不是靠关键词直接触发；模型需要实际调用工具才能发送语音或修改设置。工具会执行权限、会话范围、字数和冷却检查，失败时返回真实错误。自然语言修改的设置/词典是**全局配置**，仅管理员可以写入，普通用户可以按命令权限朗读和查看状态。不要把“这次这样读”理解成“永久加入词典”。

在“单次发音控制与持久替换词典”中选择发送方式：

| 模式 | 当前请求如何处理 |
| --- | --- |
| `hot_fix`（默认） | 采用单次结构化读音映射；如果同时有单次 instruction，则不发送这条单次 instruction。只有 instruction 而没有映射时明确提示切换模式 |
| `instruction` | 使用本次自然语言指令；如果给了单次映射，则把映射转为“将某词读作某读音”的指令，并暂时移除同词的基础/词典规则 |
| `both` | 同时采用本次 hot_fix 和 instruction |

该选择只控制**单次读音修正参数**，不限制下文的单句朗读指导。音频页的全局 instruction/hot_fix 及单独启用的持久词典仍作为基础配置使用。指令模式不能保证准确发音；对于日语人名，推荐 `hot_fix.replace` 替换为假名，不假定 `pronunciation` 支持日语罗马音。相关结构依据[阿里云 HTTP API](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)。

单次参数只存在于这一次合成调用中，不写入配置、不留在会话里供下一次使用，也不会串到其他并发会话。显示原文和语音附带的文本仍为用户的原句。

不使用聊天模型工具时，也可手动输入单次参数：

```text
/说话参数 ja {"text":"鳳凰院凶真","hot_fix":{"replace":[{"鳳凰院凶真":"ほうおういん きょうま"}]}}
/说话参数 zh {"text":"今天也辛苦了。","instruction":"请用温柔、轻松的语气表达。"}
```

第二个例子需在设置中选择 `instruction` 或 `both`。也可以在同一个 JSON 中同时给出 `hot_fix` 与 `instruction`，由当前模式选取。

## 自然语言朗读指导、停顿与分段音调

对机器人描述这句话应怎样读即可：低沉、激昂、轻声、加快、放慢、某处停顿、前后半句音调变化、句尾上扬或下降。聊天模型通过 `qwen_speak` 把这些要求传给合成器，无需用户编写 JSON 或使用新指令。聊天中明确指定的语言优先于全局翻译语言。开启“翻译模式”时，按本次明确指定的语言翻译并朗读；未指定或使用 auto 时才采用全局翻译目标。关闭翻译时按指定语言朗读原文。

- **语气与语调指导**：工具的 `delivery_instruction` 作为本次 `input.instruction` 追加到全局指令之后；读音工具的 `instruction` 仍按发音模式选取。即使发音模式为默认 `hot_fix`，也能使用单句语气指导。情绪、口音和连续升降调由模型表现，不能保证精确声学曲线。
- **精细停顿与分段变化**：模型可生成 `delivery_json`，分别指定每段原文、段尾停顿毫秒、音调、语速、音量及语气。各段文字拼接必须逐字等于原句，包含标点和空格；所有参数先校验，再发出任何收费请求。
- **输出一条语音**：逐段合成兼容的 16-bit PCM WAV，再按指定帧数追加静音并合并，保留首段的其他 WAV 元数据。分段模式固定使用 WAV、关闭 SSML；不要求目标模型支持 SSML。模型已经生成的自然停顿会保留，因此最终段间间隔可能长于追加静音。
- **限额与费用**：默认最多 8 段、总追加静音最多 10000 ms，可在“朗读指导”分类调整为 1～12 段、0～30000 ms；每段停顿 0～10000 ms，音调/语速 0.5～2，音量 0～100。整句继续受最大字数、权限、会话范围和冷却限制。每段单独请求并计费，不随意多切段。中途失败不发送半成品、不自动重试，已经成功的请求仍可能计费。
- **单次生效**：指导和分段不写入配置、不加入词典、不沿用到下次聊天调用。页面编辑器允许用户继续修改当前草稿，刷新页面后清空。选择“固定参数”模式可禁用聊天中的临时指导。

在 WebUI“生成与试听”填写“这句话怎么念（仅本次）”即可指导语气；页面不再提供手动精细分段编辑器。聊天工具仍支持单次分段指导。单句指导不会被“保存全部设置”写成默认值。

工具内部的分段格式示例（普通用户无需手填）：

```json
{
  "segments": [
    {"text": "你好，", "pause_ms": 500, "pitch": 0.9, "rate": 0.9, "instruction": "低沉、沉稳"},
    {"text": "出发吧！", "pitch": 1.2, "rate": 1.1, "instruction": "激昂，句尾上扬"}
  ]
}
```

普通单句语气指导只发一次请求；只有需要明确停顿或分段参数时才使用上述方案。不同旧模型的可选参数支持范围由服务端决定；保留模型 ID 自由输入，不强制切换到新版模型。依据官方[非实时合成说明](https://help.aliyun.com/zh/model-studio/non-realtime-tts-user-guide)、[HTTP 参数](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)及 [SSML 支持列表](https://help.aliyun.com/zh/model-studio/ssml-latex-user-guide)，不假设 `qwen-audio-3.1-tts-plus` 支持 SSML。

## 持久替换词典

在“发音与词典”中分别编辑“汉语持久替换词典（JSON）”“日语持久替换词典（JSON）”“英语持久替换词典（JSON）”并保存，例如日语词典：

```json
{
  "鳳凰院凶真": "ほうおういん きょうま",
  "OpenAI": "Open A I"
}
```

词典保存于 AstrBot 管理的插件配置中，重载或重启后仍保留。三本词典共用启用/停用开关，按实际朗读语言选择；翻译模式使用翻译目标语言。auto 未指定具体语言时不应用分语言词典。

每次合成都会把词典合并为 `hot_fix.replace`，包括自动语音、手动命令、自然语言工具和页面试听。**同词优先级：单次读音 > 持久词典 > 音频页基础 hot_fix**；跨 replace/pronunciation 冲突时也只保留优先项。未冲突的规则继续保留。原文不在本地被替换后发送给用户；接口接收待朗读文字和替换参数。词典是字面映射，不支持正则表达式；客户端使用最长词优先、非递归替换估算展开长度，超出字数上限时拒绝合成。

## 安装与首次设置

1. 在 AstrBot 插件管理中使用本仓库地址安装，或使用发布的安装 ZIP 更新。手动解压时，确保 `data/plugins/astrbot_plugin_qwen_audio_tts/` 下直接包含 `main.py` 与 `metadata.yaml`。
2. 打开插件设置中的“语音服务配置”，填写自己的 **API Key 与业务空间**；模型与匹配的音色 ID 在下方“音色配置”中填写（默认音色 + 可选的按人格规则）。业务空间填写完整域名，例如 `ws-xxx.cn-beijing.maas.aliyuncs.com` 或 `ws-xxx.ap-southeast-1.maas.aliyuncs.com`。旧配置中的短 ID 会在面板读取时迁移为北京完整域名。模型 ID 自由输入，不设固定下拉列表，支持使用本 HTTP 接口的 CosyVoice（如 cosyvoice-v3.5-plus）及旧版 Qwen-Audio-TTS 模型（如 3.0），需搭配对应音色；不把其他 API 协议的模型视为兼容。
3. 保存设置并重载插件，从插件详情或侧边栏打开“阿里云TTS助手”可视化页面。输入文字、选择语言，点击“生成音频”，生成后在页面播放器中试听或下载。
4. 使用随机语音时，关闭 AstrBot 的原生“自动 TTS”和聊天流式输出，避免冲突。插件指定朗读和页面试听不依赖随机开关或概率。

从 0.2.x 升级时，原先保存在内置提供商里的 API Key、模型和音色不会自动搬入插件，需填写到本插件的“语音服务配置”。旧的提供商选择和兼容补丁配置已移除；重载后不再修改内置 TTS 类。

公开源码和安装包不包含私人 API Key、业务空间、训练录音或 `.env`。密钥只存放在用户自己的插件配置中，页面输入框默认遮罩；试听接口不把密钥返回浏览器。使用 Python 标准库合成，无需额外安装语音 SDK。

## 分类 WebUI 与实时调参

侧边栏显示名称为 **阿里云TTS助手**。插件内部提供“生成与试听”“音色创建”“语音服务”“音色配置”“合成参数”“朗读指导”“随机语音”“发音与词典”“会话范围”“朗读与工具”分类；所有配置字段都可以在页面修改。界面使用真正的 React 19 + [Material UI 9](https://mui.com/material-ui/getting-started/installation/) 组件，支持亮/暗主题及窄屏抽屉侧栏。

组件、图标和 Emotion 样式引擎均随插件本地打包，不依赖 CDN 或外部字体。源码与锁文件在 [`frontend/`](../frontend/README.md)，安装包包含构建后的页面及第三方许可；最终依赖版本和包校验值记录在 `views/preview/build-info.json`。React/MUI 依赖保留各自许可证，插件原创代码继续使用 AGPL-3.0-only。

- **生成使用草稿**：语速、音调、音量、格式、采样率、模型、音色、指令、hot_fix、词典等调整立即参与下一次生成，不需要先保存，也不因拖动滑块自动调用收费接口。
- **保存后应用到聊天**：“保存全部设置”会校验类型、范围和参数组合，成功后立即用于后续请求。并发数修改会影响后续请求，已在执行的请求继续完成。配置版本冲突会阻止旧页面覆盖新设置。
- **密钥只写不回显**：WebUI 返回空密钥和已配置状态，留空保存表示保留原密钥，可主动更换或清除。API Key 不写入浏览器存储，不用于音频下载链接，不在日志或失败响应中回显。
- **实时调整不等于自动保存**：“重新加载”会读取服务器设置，有未保存内容时弹窗确认丢弃。试听文案/语言若保存，则成为后续默认值；单句指导和分段计划始终不保存。
- 页面使用原生音频播放器，不自动播放，可下载；浏览器不支持某格式时可改用 WAV / MP3。每次生成调用阿里云服务并按其规则计费，不自动重试。
- 试听需要 Dashboard 登录和插件权限，无需聊天适配器，不受聊天会话白名单限制。试听仅通过所有者管理页面使用。没有 `/语音试听` 或 `/试听` 指令。

普通 `_conf_schema.json` 表单无法嵌入任意播放器，本插件使用官方 `views/preview/` 可视化视图。需要支持 `AstrBotPluginView` bridge、`astrbot.api.web`、插件文件上传的 AstrBot 版本。本次按上游 `master`（版本号 4.29.1，提交 `1b10813c70949071fa11153cc4ec8c51421d13d0`）源码检查接口；旧版缺少扩展能力时，普通聊天语音可继续使用，完整 WebUI 需升级。详见[官方插件视图文档](https://github.com/AstrBotDevs/AstrBot/blob/master/docs/zh/dev/star/guides/plugin-pages.md)。

## 是否保存生成音频

“语音服务 → 保存生成的音频到本地”默认关闭。

- 关闭：页面试听读取音频后删除服务端临时文件。聊天适配器发送需要临时文件，发送完成后清理；文件服务模式延迟 60 秒清理，异常发送的临时文件最长保留约 15 分钟，插件停止时也清理。进程被强制结束时，下一次加载清理过期临时文件。
- 开启：保存在 AstrBot 插件数据根目录下的 `astrbot_plugin_qwen_audio_tts/audio/`，按“语音文件保留小时”清理，默认 24 小时。下次合成触发按小时清理，不是精确定时任务。关闭开关不会立即删除以前主动保存的文件。
- 本地开关不影响阿里云侧的数据政策，也不影响用户在浏览器主动下载的音频。

## 上传 WAV 创建音色

官方[声音复刻 HTTP API](https://help.aliyun.com/zh/model-studio/voice-clone-design-http-api)支持将本地录音编码为 `data:audio/wav;base64,...` 传入 `input.audio`，因此可以直接从 WebUI 上传，无需配置公网 OSS 或开放本地录音 URL。这是根据单段参考录音创建音色，并非把多段 WAV 累积训练成一个模型。每个音色绑定其目标模型，切换模型需重新创建匹配音色。

1. 先保存 API Key 和完整业务空间域名，再进入“音色创建”上传参考录音；公开部署先按下文配置网关限制。
2. 选择 WAV，点击“上传并校验”。上传本身不会创建音色或调用云端。只接收 16-bit PCM、单/双声道、16～192 kHz、5～60 秒且不超过 10 MiB 的文件；推荐 10～20 秒清晰单人朗读，至少 5 秒有效人声。
3. 手动填写目标模型 ID、1～10 位字母/数字前缀、参考语言和预处理选项。点击“创建云端音色”才发送一次创建请求并产生相应费用。
4. 点击“刷新任务”，取得音色 ID 后用“查询云端状态”检查部署情况，状态 `OK` 后可“填入并试听”，确认后保存全部设置应用到聊天。

复刻创建不设插件冷却或每日次数上限，由登录后台的管理员主动操作。没有批量创建、自动重复提交或自动收费重试。已有旧模型是否接受预处理等参数以服务端支持为准；关闭不支持的可选项后重试新的创建前，应先核查原任务结果。

## 上传接口安全分析与部署边界

- 所有接口走 AstrBot 官方登录桥接及 `plugin` 权限；插件再次校验登录身份。暂存上传与任务绑定 Dashboard 用户、业务空间和密钥指纹，跨用户/账号不能复用上传标识或查询任务。WebUI 不持有 API Key 原值。
- 仅允许单个 `file` 字段；先检查请求长度，再分块读取并按实际字节数限制为 10 MiB。拒绝无长度、分块传输、超限、错误扩展名和伪造 RIFF/WAVE。不能仅凭 MIME/扩展名通过。
- 校验音频块边界、PCM 编码、采样率、声道、帧长度、时长和首声道静音；去除非音频元数据块。不调用 shell、ffmpeg、压缩包解压或用户代码。技术检查不等于识别人声、版权或声纹身份。
- 录音写在非 Web 静态目录，文件名由服务端随机生成，排他创建并限制文件权限，不使用上传文件名构造路径。最多暂存 3 份录音；15 分钟后过期，后台约每分钟清理，创建结束或插件关闭时删除。复刻任务只保存 ID 和必要状态，不保存 API Key 或音频 Base64。
- 对外请求固定到经白名单验证的百炼北京/新加坡 HTTPS 业务空间域名；录音使用 Data URI，不接受用户提供的远程录音 URL，拒绝带密钥请求重定向。避免任意 URL 抓取和密钥跨主机转发。
- 创建之前先持久化任务记录；同一上传标识重放返回原任务，不再次调用创建。崩溃或超时结果未知时标记 `UNKNOWN`，禁止自动重建；需在百炼控制台核查。无 ID 的未知结果不能凭空恢复 ID。任务记录损坏时停止接受新创建，以保留防重复提交保护。任务日志按单个 AstrBot 进程设计，不支持多个副本同时共享该数据目录。

**已确认的宿主边界：** 当前 AstrBot 的 [`bind_quart_request_context`](https://github.com/AstrBotDevs/AstrBot/blob/master/astrbot/dashboard/asgi_runtime.py) 在进入插件 handler 前执行 `await request_.body()`，会读取完整请求体。因此插件里的 Content-Length 检查和分块读取**不能代替接入层的总请求大小限制**。本插件未修改宿主的请求运行机制。对外提供上传前，应在反向代理/网关启用请求大小、超时和限速，并禁止绕过网关直连后台端口。

例如 Nginx 的 AstrBot `server` 块可设置：

```nginx
client_max_body_size 11m;  # 为 10 MiB WAV 留出 multipart 开销
client_body_timeout 30s;
```

同时按自己的部署设置请求速率限制和登录访问控制。该限制应覆盖所有可访问的 AstrBot 插件路由，而不只前端使用的单个 URL。尚未在目标部署上验证代理配置，不将本地文件校验描述为完整抗拒绝服务保护。

## 随机语音

默认转换 20% 的符合条件的完整 AI 回复，最多 200 字，同一会话间隔至少 10 秒。概率范围 0～100，可以在设置页面调整。

- 达到最大字数、冷却中、抽取未命中、包含图片/卡片/语音等非文字组件时，发送原消息。
- 默认跳过代码块；可清理用于朗读的 Markdown、网址和图片链接。原始文字不会被清理或截断。
- 最大字数是清理后 Python Unicode 字符数，包括标点、空格和英文字母，不是英文单词数。多段文字合并后检查上限，每个结果抽取一次。超过上限不会偷偷截断。
- 可以选择只发语音，或语音和原文同时发送。合成/下载失败时保留原始文字。
- 开启“随机语音 → 文字先发，语音后台生成”（`reply.text_first`）后，发送前钩子不再等待翻译和合成，完整原文由 AstrBot 正常发送；后台任务同时翻译、合成和下载，收到发送后钩子后再单独发送语音，即使语音很快生成也不会抢在原文之前发送。实现依据 [AstrBot 消息事件钩子文档](https://docs.astrbot.app/dev/star/guides/listen-message-event.html)。
- 文字先发默认关闭；开启后自动回复始终保留原文，优先于 `dual_output`，不重复发送文字。仍适用概率、字数、范围、冷却和同一会话仅一个进行中任务的限制；语音未完成时新回复仍发送文字。命令、工具及试听不受此开关影响。
- 后台任务使用接收该回复时的配置快照；翻译、合成和补发失败只记录错误类型，不撤回或改写文字。生成后最多等待 300 秒的原文发送后钩子，未收到则丢弃本次补发。临时文件在语音发送后清理，文件服务保留 60 秒供适配器读取；插件卸载取消后台任务并清理临时文件。
- 可以设置仅私聊、仅群聊、平台白名单、会话白名单/黑名单。黑名单优先。在目标会话发送 AstrBot 内置 `/sid`，将返回的 **UMO 完整值**复制到会话列表，不带「」；不要填写 UID 或单独的 Session ID。插件不再注册会话标识命令。
- 仅拦截 AstrBot 发送前钩子中的完整结果；不拦截其他插件直接 `event.send()` 的主动消息，也不拦截已经开始发送的流式片段。

## 指定语言朗读

```text
/说话 zh 你好，很高兴认识你。
/说话 en Hello, nice to meet you.
/说话 ja こんにちは。お会いできてうれしいです。
```

命令别名：`/朗读`、`/qvoice`。语言也可填写 `中文`、`汉语`、`英语`、`日语` 等名称。使用同一个复刻音色跨语言朗读，实际效果取决于模型和参考录音。给中文文字加 `en` 在关闭翻译时不会翻译；启用翻译模式后，本次翻译目标以 `en` 为准，即使全局设为日语也会翻译为英语。使用 `auto` 或自然语言中未明确指定语言时，先采用全局翻译目标，再回退默认朗读语言。本次覆盖不修改已保存的设置。指定句子同样受最大字数、会话范围和并发数限制，但不受随机概率限制。默认任何用户可用，可设为仅管理员使用，默认同用户同会话冷却 3 秒。

管理员可在聊天中修改全局设置，也支持上文的自然语言工具：

```text
/语音设置 概率 30
/语音设置 字数 300
/语音设置 开关 开
/语音设置 开关 关
/语音设置 发音模式 both
/语音设置 词典开关 开
```

具体命令前缀按 AstrBot 的唤醒/命令前缀设置使用；本说明以 `/` 为例。

## 模型和音色

在插件“音色配置”中选择模型和对应复刻音色；WebUI 的“音色配置”页把默认音色、人格规则表格（人格下拉、按语言细分、增删）和规则 JSON 放在一起，与插件设置面板修改的是同一份配置。随机语音、朗读和试听都从这里取模型与音色。没有命中人格规则时使用“默认音色”。下面是格式示例，请替换为自己账户中创建的实际音色 ID：

| 模型 | 音色格式示例 |
| --- | --- |
| `qwen-audio-3.1-tts-plus` | `qwen-audio-3.1-tts-plus-myvoice-实际唯一标识` |
| `qwen-audio-3.1-tts-flash` | `qwen-audio-3.1-tts-flash-myvoice-实际唯一标识` |

复刻音色属于创建它们的账户和业务空间，不能直接使用示例字符串。切换模型必须切换匹配音色。支持 Qwen-Audio-TTS 和 CosyVoice（包括 `cosyvoice-v3.5-plus`）的业务空间 HTTP 接口。模型名称自由输入，不设前缀、版本白名单，也不根据音色 ID 前缀猜测绑定关系；模型与音色的实际兼容性由云端校验。不同协议的模型仍需对应 API 适配。CosyVoice HTTP 合成目前限北京地域，详见[官方文档](https://help.aliyun.com/zh/model-studio/cosyvoice-tts-http-api)。

### 获取模型列表

“音色配置”页的“获取模型列表”按钮按已保存的 API Key 与业务空间读取服务端模型清单，成功后模型字段变成可直接选择的下拉框（仍可输入任意模型 ID）。请求顺序是 `https://<业务空间域名>/v1/models`（OpenAI 兼容路由）→ `<API 基址>/models`（DashScope 路由）；两条都不可用、未保存凭据或网络异常时，界面给出可读提示并保持手动填写可用。

音色字段同样是可输入的下拉框，候选来自三处并去重：服务端音色列表（“获取音色列表”）、本机音色库（`voice_library`）、配置里已经用到的音色；再按“音色 ID 以模型名开头”筛选：选了 `qwen-audio-3.1-tts-plus` 就只列 `qwen-audio-3.1-tts-plus-…` 开头的音色。按语言细分的配对先用该语言自己的模型筛选，该语言模型留空时回退到同一条规则或默认音色的模型。筛选不到候选时仍可手动填写，插件不会清空已填写的值。

### 获取音色列表

“获取音色列表”调用官方的音色查询接口，读取该业务空间通过 API 创建的音色（复刻音色、设计音色）：

```http
POST https://{业务空间域名}/api/v1/services/audio/tts/customization
{"model": "voice-enrollment", "input": {"action": "list_voice", "page_index": 0, "page_size": 50}}
```

返回的 `output.voice_list` 每条包含 `voice_id`、`target_model`、`status`、创建/修改时间；插件按 `total_count` 自动翻页（最多 200 条），只保留 `voice_id`、`target_model` 与 `status`，`status` 不是 `OK` 的音色会在下拉里标注。`prefix` 参数实测不会按模型前缀过滤，所以插件改为本地按模型名筛选。该接口只列出“通过 API 创建”的音色；控制台里手工上传的音色若未出现在列表，仍可手动填写 ID。

限制与预期：

- 清单来自服务端网关的模型目录，不等于“都能用于 TTS”：条目可能包含聊天、向量、图像等模型，插件不按名称过滤逻辑做校验，最终能否合成由云端判断。自建网关（如 new-api）通常只列出该令牌可用的模型。
- 音色清单只包含“通过 API 创建”的音色，且以 `voice_id` 为准；插件不根据模型名推测可用音色，也不会自动改写已填写的值。
- 官方业务空间域名不提供 `/v1/models`（实测 404），因此“获取模型列表”在官方域名下会失败并提示手动填写；模型 ID 仍可手填（例如 `qwen-audio-3.1-tts-plus`、`qwen-audio-3.1-tts-flash`、`cosyvoice-v3.5-plus`）。
- 按钮不会自动触发，也不会覆盖已填写的模型与音色。

### 人格音色规则

“音色配置”中的 `人格音色规则（JSON）` 让同一个插件为不同 AstrBot 人格使用不同声音。插件在每次朗读时读取当前会话的人格（AstrBot 人格管理中的人 `persona_id`，会话内用 `/persona` 切换），按下列顺序选择模型与音色：

1. 命中的人格规则：开启 `per_language` 时先按最终朗读语言取 `zh_`/`en_`/`ja_` 配对，该语言未配置则用规则自身的 `model`/`voice`；
2. 默认音色：开启“默认音色按语言区分”时先按语言取配对，否则用默认模型与音色；
3. 全部为空时提示到“音色配置”中填写，不会退回内置 TTS。

示例：

```json
[
  {"persona": "kuchiba-chisa", "per_language": false, "model": "qwen-audio-3.1-tts-plus", "voice": "qwen-audio-3.1-tts-plus-myvoice-千咲"},
  {"persona": "whale-chan", "per_language": true, "zh_model": "qwen-audio-3.1-tts-plus", "zh_voice": "qwen-audio-3.1-tts-plus-myvoice-鲸鱼"}
]
```

限制：同一人格只能有一条规则；每条规则至少配置一组模型与音色；模型与音色只能成对填写或成对留空；规则数量不超过 50 条。命令 `/语音设置 音色配置 设置|语言|默认|默认语言|删除|开关|列表` 可以完成同样的修改，管理员权限与 `/语音设置` 一致。

从 1.1.2 升级时，插件启动会把旧 `connection.model`/`connection.voice` 与旧“按语言选择模型与音色”迁移为默认音色（按语言开关一并保留），随后删除旧字段；迁移只执行一次，之后的修改以“音色配置”为准。切换配置档案时音色配置随档案一起切换。

## 参数面板

按[阿里云非实时 HTTP API](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)传入 `input`：

| 设置 | 默认 | 范围或说明 |
| --- | --- | --- |
| 格式 `format` | wav | wav / mp3 / opus；PCM 缺少文件头，不作为直接发送选项 |
| 采样率 `sample_rate` | 24000 | 8000 / 12000 / 16000 / 22050 / 24000 / 44100 / 48000；Opus 不支持 22050、44100 |
| 音量 `volume` | 50 | 0～100 |
| 语速 `rate` | 1.0 | 0.5～2.0 |
| 音调 `pitch` | 1.0 | 0.5～2.0 |
| Opus 码率 `bit_rate` | 32 | 6～510，仅 Opus 时发送 |
| 种子 `seed` | -1 | -1 不指定；0～65535 固定种子 |
| 目标语言 `language_hints` | auto | auto 不传；可选 zh / en / ja；命令参数优先 |
| 情绪指令 `instruction` | 空 | 可描述情感、方言和说话方式，具体模型支持情况以服务为准 |
| `enable_ssml` | false | 只用于支持 SSML 的模型及单段指定朗读/试听；自动聊天和精细分段始终关闭 |
| `hot_fix` | 空 | pronunciation 和 replace 的 JSON 配置，设置面板内有示例 |
| AIGC 标识及传播者字段 | 关闭/空 | 开启后发送对应参数；修正 WAV 文件头时保留其他数据块 |

本插件采用非流式 HTTP 合成后发送完整文件，没有暴露仅流式模式可用的字级时间戳参数。不要同时开启原生自动 TTS 与插件随机转换。模型不支持某个参数时接口会返回错误；可以先清空 instruction / hot_fix 等可选设置再检查。

超时默认单次操作 60 秒；不自动重试已发送的合成请求，避免重复计费。最大并发默认 2，可设置 1～8。开启本地保存后，生成音频默认保留 24 小时；关闭时采用上述临时文件清理。支持可选 AstrBot 文件服务，适合适配器和 AstrBot 分离部署，需要先配置可访问的 `callback_api_base`。
